===========================================================
RETRO-GO MICROSD CARD INSTRUCTIONS
===========================================================

1. FORMAT YOUR MICROSD CARD:
   - Format: FAT32 (or exFAT if your card is larger than 32GB, but FAT32 is recommended).
   - Cluster size: 32KB or Default.

2. HOW TO COPY:
   - Copy the "roms" folder directly to the ROOT of your MicroSD card.
   - Result on SD card:
       D:\roms\nes\
       D:\roms\snes\
       D:\roms\gb\
       D:\roms\gbc\
       D:\roms\gba\
       D:\roms\md\
       D:\roms\sms\
       D:\roms\gg\
       D:\roms\pce\
       D:\roms\doom\
       ...

3. FOLDER TO CONSOLE MAPPING & SUPPORTED EXTENSIONS:
   - /roms/nes/     -> Nintendo Entertainment System (.nes, .fc, .fds, .zip)
   - /roms/snes/    -> Super Nintendo (.smc, .sfc, .zip)
   - /roms/gb/      -> Game Boy (.gb, .zip)
   - /roms/gbc/     -> Game Boy Color (.gbc, .zip)
   - /roms/gba/     -> Game Boy Advance (.gba, .zip)
   - /roms/md/      -> Sega Mega Drive / Genesis (.md, .gen, .bin, .zip)
   - /roms/sms/     -> Sega Master System (.sms, .sg, .zip)
   - /roms/gg/      -> Sega Game Gear (.gg, .zip)
   - /roms/pce/     -> PC Engine / TurboGrafx-16 (.pce, .zip)
   - /roms/doom/    -> DOOM (.wad: doom1.wad, doom.wad, doom2.wad, etc.)
   - /roms/msx/     -> MSX (.rom, .mx1, .mx2, .dsk)
   - /roms/col/     -> ColecoVision (.col, .rom, .zip)
   - /roms/gw/      -> Game & Watch (.gw)
   - /roms/lnx/     -> Atari Lynx (.lnx, .zip)

4. SAVES & COVERS:
   - Save games will automatically be saved to /saves/<console>/
   - Box art / covers can optionally be placed in /covers/<console>/
===========================================================
